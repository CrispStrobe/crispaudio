# Sample walkthroughs

File → Sample Walkthroughs offers Recording, Takes & comp, Mixing, and Video &
audio. Choose one and load its sample through the normal Sample Sessions dialog.
Loading retains existing sources and the previous project in Undo. All audio is
original deterministic synthesis; the picture sample includes bundled generated
video and titles. There are no external sample downloads.

A compact modeless guide shows one of four steps. Previous/Next changes the step;
Open tool invokes the same command as desktop menus or the touch ribbon. Tools
never auto-arm a microphone, start recording, apply a mix or export merely because
a guide opened. Close/Done dismisses the guide. Loading another project or undoing
the sample load dismisses a guide that no longer belongs to the project.

- Recording: add/arm a track, select an input in collapsed setup, capture speech,
  stop and listen. Built-in MacBook input is user-confirmed; monitoring stays off
  for speakers. More physical devices can be checked when available.
- Comp: use the two alternate key takes, audition take/comp, select a region,
  replace/remove it, then save and recall a comp version.
- Mixing: explore the three-track FX/automation mix, capture A/B, compare at
  matched loudness, restore the preferred mix and review an export.
- Video: play the picture/music/title session, inspect a segment, adjust fades or
  color, trim boundaries, export and check the saved movie's sync.

The guides work alongside focused dialogs rather than adding a permanent ribbon
of tutorial text. Extra explanation is available from the information button.
English and German guides fit narrow touch layouts. Physical iPad acceptance
remains a hardware check; Chrome/WebKit sample load/undo/navigation is automated.
