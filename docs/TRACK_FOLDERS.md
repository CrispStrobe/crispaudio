# Track folders

View → Track Folders opens a compact editor. Enter a name and choose member tracks.
Each track belongs to at most one folder; assigning it elsewhere moves its membership.
Dissolve removes the folder, preserving every track, clip and route.

The folder arrow collapses its tracks into one header row. Playback and export still
use all member tracks. Folder M and S set mute or solo on every member in one undo.
A locked member disables those shared controls. The selection icon selects all folder
clips and their linked/grouped partners; nudge, cut/copy and delete use the selection.

Folders persist in projects and their membership follows track removal. They organize
the timeline without changing bus/send routing or creating a new audio processing node.
