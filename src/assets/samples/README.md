# Original sample media

`picture.mp4` is a 12-second procedural RGB motion graphic encoded as H.264,
640×360 at 25 fps, with no audio. It was generated for CrispAudio and is licensed
under the repository's MIT license. No external footage or recordings are used.

Reproduce it with `sh scripts/generate-sample-video.sh`. Sample audio is generated
by the original deterministic synthesis in `src/lib/sampleSessions.ts`.
